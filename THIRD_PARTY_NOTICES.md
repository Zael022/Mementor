## Aceternity UI · File Upload
`frontend/src/Componentes/CargaArchivo.jsx` adapta la estructura del componente File Upload de Aceternity UI (https://ui.aceternity.com/components/file-upload): zona con patrón de cuadrícula, `react-dropzone` y una ficha animada con Motion. Se reescribió en JSX con los estilos del proyecto. Antes de redistribuir el proyecto, revisa la licencia vigente en el sitio de Aceternity UI: no se pudo consultar desde el entorno donde se hizo esta adaptación.
